1Cómo está armado

Cinco piezas. Cada una puede fallar sola, y el panel te dice cuál.

botikin.app la web y la página de activación (Vercel) │ ├─ Flow cobra los $3.990 (flow.cl) ├─ SMTP manda el código por correo (GoDaddy) │ ▼ Kapso recibe y envía los WhatsApp (+1 201 801 8270) │ ▼ Supabase la base y el cerebro del agente └─ Claude Opus 5 lee cajas, lee recetas, conversa

Kapso es solo el cartero. El cerebro del agente vive en nuestro código, en una Edge Function de Supabase, y su carácter en el archivo soul.md. Si mañana cambiamos de proveedor de WhatsApp, se reescribe un archivo y nada más.

2El panel

botikin.app/admin · pide una clave. Se refresca solo cada 30 segundos.

Arriba: las alertas primero, después el embudo y los servicios.

El embudo

Son cinco pasos por los que pasa la misma persona, en orden. Si un número es menor que el anterior, ahí se está perdiendo gente y el recuadro se pinta en ámbar.

PasoQué significa si cae
Pagó—
Recibió su códigoUn pago sin código: revisar el webhook de Flow
Activó por WhatsAppEl más caro. Pagaron y no entraron
Contó su casaEntraron y abandonaron el onboarding
Cargó un remedioNunca llegaron al momento que da valor
El envío del correo se mide aparte. No es una etapa donde la gente se caiga, es una entrega: mezclarlo con el embudo hacía parecer que se perdía gente cuando solo faltaba despachar un correo.

Los servicios

Cuatro luces. Verde es que respondió en esta misma consulta, no que respondió alguna vez.

  • Supabase — si está roja, no hay base: nada funciona
  • WhatsApp — muestra el número, su estado y si el webhook apunta a Botikin. Si no apunta, los mensajes entrantes se pierden sin dar error
  • Correo — dice por qué vía sale y cuántos códigos se despacharon
  • Recaudado — total cobrado y cuántos pagos fallaron
Abajo: uso, últimos pagos, códigos sin canjear y las casas.

"Códigos sin canjear" es la tabla que más hay que mirar. Cada fila es alguien que pagó y todavía no entró. La columna correo enviado dice si el código salió o hay que entregarlo a mano.

3Qué hacer con cada alerta

Pagó y no ha activado hace más de un día

La más cara y la más silenciosa: nadie reclama, simplemente no vuelve. El panel te da el correo y el código. Escríbele a esa persona con su código y el link de WhatsApp. Si son varios el mismo día, revisa que el correo esté saliendo.

El webhook de Kapso no apunta a Botikin

Los WhatsApp entrantes se están perdiendo sin ningún error visible: la gente escribe y nadie responde. Entra a Kapso → el número → Webhooks y confirma que el activo apunte a la función de Supabase.

Tratamientos terminados marcados como activos

Riesgo real: recordarle a alguien una toma de algo que ya terminó. Se arregla corriendo cerrar_tratamientos_vencidos() en el editor SQL de Supabase.

El número se muestra con otro nombre

Quien recibe el mensaje ve ese nombre junto a un +1 desconocido. Se cambia en Kapso y pasa por aprobación de Meta.

El correo sale por SMTP del buzón

No es un problema hoy, es una deuda: techo de unos cientos diarios y sin registro de rebotes — si un correo no llega, nadie se entera. Migrar a Resend son tres registros DNS.

4Tareas de todos los días

Emitir un código a mano

Para una invitación sin cobro (prensa, prueba, un amigo). En Supabase → SQL Editor:

select * from issue_access_code('persona@correo.cl', 'Nombre', 'manual');

Es idempotente por correo: si esa persona ya tiene un código vivo, te devuelve el mismo en vez de crear otro.

Anular un código

update access_codes set status = 'revoked' where code = 'ABCD-EFGH';

Ver la conversación de una casa

select direccion, texto, created_at
from mensajes
where hogar_id = (select id from hogares where telefono = '+569XXXXXXXX')
order by created_at;

Mover una casa a otro teléfono

Cuando alguien cambia de número. Nunca borres y recrees el hogar: se llevaría por delante a la familia, el inventario y los tratamientos.

update hogares set telefono = '+569NUEVO' where telefono = '+569VIEJO';

Registrar un pago que llegó por otra vía

select * from registrar_pago(
  'orden-flow', 3990, 'exitoso', 'persona@correo.cl',
  'Onepay', '1234', now(), '{}'::jsonb);

Devuelve el código de acceso. Es idempotente por número de orden: si Flow reintenta la notificación, no genera dos códigos.

Probar que el correo sale

curl -X POST https://botikin.app/api/probar-correo \
  -H "x-panel-clave: LA_CLAVE" \
  -H "content-type: application/json" \
  -d '{"para":"tu@correo.cl"}'

6Cuando algo se cae

Nadie recibe respuesta en WhatsApp

  1. Panel → servicio WhatsApp: ¿el webhook apunta a Botikin?
  2. Supabase → Edge Functions → whatsapp → Logs
  3. Si dice firma inválida: cambió el secreto del webhook en Kapso
  4. Si dice claude: se acabó el crédito de Anthropic o hay un error de modelo

El agente responde varias veces a una ráfaga de mensajes

Es el búfer de Kapso apagado. Debe estar en 8 segundos con buffer_enabled activo, para que cuatro fotos seguidas sean un solo turno y una sola respuesta.

Alguien pagó y no le llegó el código

  1. Panel → Últimos pagos: ¿aparece la orden?
  2. Si aparece con código, mándaselo tú por correo o WhatsApp
  3. Si no aparece, el webhook de Flow no llegó: regístralo a mano con registrar_pago()
La regla de oro: el código siempre se muestra en pantalla al terminar el pago, así que un problema de correo nunca deja a nadie afuera. Por eso el correo es respaldo y no camino único.

7Lo que todavía falta

Deudas conocidas, en orden de urgencia.

QuéPor qué importa
El cobro no se renueva solo Flow no tiene habilitado el cargo automático (error 7001), así que hoy cada mes hay que recobrar. Pedirle a Flow el contrato de cargo automático.
Sin plantillas aprobadas por Meta El agente no puede hablar primero: fuera de la ventana de 24 horas solo se permiten plantillas. Sin ellas no hay recordatorios de toma ni avisos de vencimiento — que es la mitad del producto.
El proceso diario de vencimientos Nadie revisa los vencimientos cada mañana todavía. Depende de lo anterior.
Sin catálogo del ISP El agente detecta duplicados por coincidencia exacta de principio activo. Con el registro del ISP reconocería equivalencias entre marcas.
Las recetas no se guardan Se leen y se crean los tratamientos, pero el documento original y el nombre del médico no quedan archivados.
Correo por SMTP Techo diario y sin registro de rebotes.
